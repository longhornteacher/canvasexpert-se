# Scoring rules

Teacher policy updated 2026-10-09 (names: see the vocabulary in [ARCHITECTURE.md](ARCHITECTURE.md)): the agent assesses work honestly using the Canvas rubric when available, or a common-sense local scoring basis when absent; the Engine posts it. A missing Canvas rubric is not a blocker. Always post the computed assessment, even below an existing entered grade. Never consider a higher entered grade when choosing the assessment or deciding to post; the teacher handles later raises.

Keep the rubric and feedback honest. Do not inflate criteria to match a teacher's final grade or call a skipped rubric complete. Compare revisions with the strongest preceding academic attempt from work and rubric evidence.

The agent infers response units and defensible weights. For a rubric repeated across components, normalize component weights to shares a_i; aggregate each criterion q_j = sum_i(a_i * s_ij), then assess P * sum_j(q_j) / sum_j(m_j), using live assignment maximum P and rubric criterion maxima m_j. If criteria already correspond to distinct prompts, use that mapping instead of repeating them. Preserve calculation precision; round the proposed posting/display score to two decimals with deliberate precision. Use real rating IDs only when they truthfully match the awarded points. Zero-point descriptive criteria do not enter the denominator; do not invent a numeric basis for a wholly unscored rubric. A no-Canvas-rubric assignment requires an explicit local scoring basis.

Feedback order: overall computed assessment, compact per-response criterion scores, conversational glows/grows grounded in the work. Full rubric definitions remain in Canvas. Teacher-only notes never enter student output.

Rubrics the Engine attaches disable automatic grade calculation. Do not silently change existing rubric coupling. Post the honest rubric assessment and computed grade normally, including coupled assignments; confirm returned rubric/grade outcomes and report uncertainty honestly. Do not invent a preservation guarantee. Independent-rubric and no-rubric work need no workspace certification metadata.

Canvas exclusively calculates late point penalties. The agent determines lateness from the actual work (the first genuine current or prior submission, excluding blank, placeholder or accidental ones; later drafts inherit it), the school calendar and teacher/student notes, and supplies `late_timing` with `status`, `seconds_late`, `due_at` and `basis`. The Engine writes only `late_policy_status` and `seconds_late_override` to the current attempt, after checking that the attempt is still current and Canvas's live due date still equals `due_at`; it never reads the calendar or adjusts points. Missing or unclear inputs mean the agent omits timing, tells the teacher, and continues the grade and comment. See [ARCHITECTURE.md](ARCHITECTURE.md) for current boundaries. [Historical evidence](docs/0.1b-evidence.md) is observation, not a runtime prerequisite.
