# Scoring rules

Teacher policy updated 2026-10-12 (folder names: Dev, UserInstall, UserSync; see [ARCHITECTURE.md](ARCHITECTURE.md)). The agent assesses work honestly using the Canvas rubric when available, or a common-sense local scoring basis when absent; the Engine posts the supported assessment output. A missing Canvas rubric is not a blocker. For ordinary assignments, always post the computed assessment, even below an existing entered grade. Never consider a higher entered grade when choosing the assessment or deciding to post; the teacher handles later raises.

New Quizzes, including written-response items, are open for authoring, use and scoring within supported limits. For written work, pull the explicitly selected quiz by assignment ID, assess typed responses and uploaded files, and use `operation: comment-only` with a `comment_only` body containing the exact `attempt`, component criterion scores and `feedback`. Use the attached rubric or an explicit local `scoring_basis`; the Engine validates arithmetic and posts one whole-assignment comment per student. The comment starts with criterion scores and contains no aggregate quiz assessment. This operation never writes a quiz/item grade, rubric assessment or late timing; the teacher enters item points in SpeedGrader. Missing/unreadable evidence holds that student's feedback and independent students continue. Local-test and pending live evidence labels describe confidence, not a blanket prohibition on teacher use.

Keep the rubric and feedback honest. Do not inflate criteria to match a teacher's final grade or call a skipped rubric complete. Compare revisions with the strongest preceding academic attempt from work and rubric evidence.

For a shared group assignment, `pull-work` produces source-linked `group-packet` and `group-work` evidence while retaining each student's submission, attempt, grade, effective dates, flags and comments. A shared artifact does not prove each member contributed. Treat unknown membership, placeholder/no-attempt rows, incomplete audience reads and unreadable files as unknown evidence rather than missing work. If current artifacts or attempts differ, keep shared assessment on hold. A ready group (known `grade_group_students_individually: false`, complete assignment-specific audience, one current artifact and attempt) is assessed once with `kind: group-results`: the shared grade and rubric are computed with the ordinary exact arithmetic, never multiplied by contribution, and reach every member together, so a subset request, changed member or attempt, or excused or hidden member holds that group. Whole-group comments and private per-student comments are separate actions; private text never enters shared payloads. Individual group-grading mode is not yet supported, and ordinary `results` remain refused on any group assignment. Pulling evidence alone never authorizes a write.

The agent infers response units and defensible weights. For a rubric repeated across components, normalize component weights to shares a_i; aggregate each criterion q_j = sum_i(a_i * s_ij). Ordinary assignment grades assess P * sum_j(q_j) / sum_j(m_j), using live assignment maximum P and rubric criterion maxima m_j. New Quiz comment-only results use validated component/criterion arithmetic without displaying or posting an aggregate quiz assessment. If criteria already correspond to distinct prompts, use that mapping instead of repeating them. Preserve calculation precision; round proposed posting/display scores to two decimals with deliberate precision. Use real rating IDs only when they truthfully match the awarded points. Zero-point descriptive criteria do not enter the denominator; do not invent a numeric basis for a wholly unscored rubric. Work without a Canvas rubric requires an explicit local scoring basis.

Ordinary assignment feedback order: overall computed assessment, compact per-response criterion scores, conversational glows/grows grounded in the work. New Quiz written-work feedback starts with criterion scores, then glows/grows; omit an aggregate quiz assessment. Full rubric definitions remain in Canvas. Teacher-only notes never enter student output.

Rubrics the Engine attaches disable automatic grade calculation. Do not silently change existing rubric coupling. For ordinary assignments, post the honest rubric assessment and computed grade normally, including coupled assignments. For New Quiz written work, the rubric is a scoring basis for the comment only. An accepted grade/rubric/comment write counts as done: report once and stop, without post-write readbacks or reply-shape confirmation. Preserve pre-write identity, attempt, scope, basis and duplicate checks; resume genuinely failed or interrupted work from saved outcomes. Independent-rubric and no-rubric work need no workspace certification metadata.

For ordinary assignment grading, Canvas exclusively calculates late point penalties. The agent determines lateness from the actual work (the first genuine current or prior submission, excluding blank, placeholder or accidental ones; later drafts inherit it), the school calendar and teacher/student notes, and supplies `late_timing` with `status`, `seconds_late`, `due_at` and `basis`. The Engine writes only `late_policy_status` and `seconds_late_override` to the current attempt, after checking that the attempt is still current and Canvas's live due date still equals `due_at`; it never reads the calendar or adjusts points. Missing or unclear inputs mean the agent omits timing, tells the teacher, and continues the grade and comment. New Quiz comment-only results carry no lateness actions. See [ARCHITECTURE.md](ARCHITECTURE.md) for current boundaries.

Posting gate (decided 2026-10-10, built for scoring, new assignments and quizzes): scores are reviewed by the teacher on the review page before posting unless the teacher explicitly skips review. Review changes when posting happens, never what is posted: the page shows the same computed assessment `post` will write.
