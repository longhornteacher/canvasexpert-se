CanvasExpert-SE program folder
==============================

This folder holds only the program. Keep it separate from your synced
workspace folder (the one with students, settings and courses).

1. Unzip this somewhere that is NOT your synced workspace, for example
   C:\Users\<you>\CanvasExpert-SE-program.
2. Double-click webui.cmd. The hub opens in your browser. This also links this
   computer to the program, so the workspace's cse.cmd can find it.
3. In the hub, connect Canvas, then click Browse and pick your synced
   workspace folder. If it is empty or new, the hub creates the starter files
   for you; nothing existing is ever overwritten.

Repeat step 2 on each computer you use. Your Canvas token is stored per
computer in Windows Credential Manager and is never written to a file.
