# Personal rubric definitions

Save a `kind: rubric-library` definition here only when the teacher asks. The
filename stem is its portable library key. Rubric reads and draft export are
supported. Use `rubric: {library: "filename stem"}` on a new assignment, graded
discussion or rubric-attachment draft. An identical course rubric is reused;
a changed definition creates a new course copy for new attachments and keeps
earlier assessments intact. Existing Canvas rubrics also accept `rubric: {id: N}`.
