# Book-club family messages

Read `family-contact.md` and the relevant unit context first. Use `group-work.md` only when also changing clubs or course materials; an email request alone does not authorize membership, assignment or grade changes.

Use current Engine group reads to find each requested course's exact collaborative group set, book groups and stable student references. Group names can differ in case or whitespace across courses. One book version may target matching groups in several courses. Prepare the full run once so a student in two audiences is reported instead of getting two emails.

Write each book's version from the teacher's actual book choices, description, reading schedule and expectations. Include its locally saved cover inline and attach the requested schedule if useful. Do not invent plot details, reading dates or family obligations. Do not list other members' names. An empty group needs no email; report it briefly. Explain unmatched students and leave them skipped unless the teacher chooses their message.

Prepare with `prepare_family_contact`, then use the shared private review page so the teacher can check each book version and the recipients before Send or Drafts only. Follow the general playbook for changed membership and delivery outcomes.
