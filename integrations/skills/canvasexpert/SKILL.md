# CanvasExpert-SE

This skill only gets you to the teacher's local CE-SE **Install**: the folder with the Engine, `AGENTS.md`, `playbooks/`, `context/` and `cse.cmd`. Teachers do not need Source (the development checkout) or Sync (an optional cloud folder that holds their shared rules; each Install reads it directly). In tools, "workspace" means Install. Everything about how to work lives in Install's own files, which belong to the teacher and override anything here.

1. **Find Install's instructions.** For "install this", use the extracted folder's bundled Engine and read its `playbooks/install.md`, even if another CE-SE MCP server is already connected; never configure the teacher against an unrelated Install or hand them terminal commands. For teaching tasks with CE-SE MCP tools connected, read `AGENTS.md` with `read_workspace_file` and use `list_workspace_files` to find the playbook, context or course file you need. Without MCP, find the folder containing `AGENTS.md`, `playbooks/`, `context/` and `cse.cmd`; if neither route works, ask the teacher to share their extracted Install. Never work from memory of how CE-SE behaves.
2. **Read `AGENTS.md`, then only the playbook the task needs.** If the active rules location is unclear, check `engine_info` rules-location. If configured Sync is unavailable, report the path problem instead of using inactive local copies.
3. **Read saved courses first.** `list_courses` defaults to `source: configured` and returns the Install `root`, Canvas `instance` and saved course fields with no Canvas call; use `source: canvas` only for connection testing or choosing more courses. Compare `root` with the Install you intend before teacher work; a connection registered to another folder needs re-registration, so do not repeat setup in the wrong folder.
4. **Prefer connected CE-SE MCP tools** and follow the mapping in Install's `AGENTS.md`. Review is the default for gated writes; skip it only on the teacher's explicit request or a playbook-permitted resume. Preserve requested scope, honest assessments, hashes, receipts and returned outcomes. New Quiz written work (`ESSAY`, `FILEUPLOAD`) is supported; scoring posts only a comment with criterion scores, and the teacher enters item points in SpeedGrader.
5. **Never open, list or search `.cse/`, or inspect private setup or student browser pages.** Give the teacher private page links to operate themselves. Read-only API JSON can contain real names; keep teacher-only information out of student output.
6. **Use the teaching profile.** Read `context/teaching-profile.md`, grading preferences and relevant references before educational judgments; an incomplete profile does not block ordinary work, and no developer class or tag policies are defaults.
