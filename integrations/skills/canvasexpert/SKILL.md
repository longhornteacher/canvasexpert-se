# CanvasExpert-SE

The teacher's CE-SE workspace holds everything you need. This skill only gets you there.

1. **Find the workspace.** It is the folder containing `AGENTS.md`, `playbooks/`, `context/` and `cse.cmd`. If you can't see it, ask the teacher to share or attach that folder. Don't proceed without it, and don't work from memory of how CE-SE behaves.
2. **Read its `AGENTS.md`, then only the playbook the task needs.** Those files belong to the teacher and override anything here. `AGENTS.md` explains how to reach the Engine from where you are working.
3. **When CE-SE MCP tools are available, use the named tools in `AGENTS.md`** for Engine reads, draft files, validation, and the review-page round trip. The teacher must approve gated writes on the CE-SE page.
4. **Never open, list or search `.cse/`** inside the workspace. It holds the private student mapping, and outside Claude Code nothing else blocks it.
