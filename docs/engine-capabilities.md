The page's lights describe recorded evidence, not real-time Canvas health. Keep three kinds of evidence distinct and never present one as another:

- **Canvas Live**: observed against a real Canvas (course CS8, 121046, unless noted).
- **Local tests**: Go tests, fakes, temporary fixtures, synthetic browser pages. They prove code behavior, not Canvas or client behavior.
- **Pending human validation**: needs a teacher, a real client, or a student view. A pending item is an evidence limit, not a prerequisite for ordinary supported use.

## Native UserSync folder chooser (2026-10-15, local checks)

The teacher reported Browse failing on this Windows installation. `platform.PickFolder` now uses Windows Shell APIs directly instead of spawning PowerShell and Windows Forms. It requires no PATH entry, PowerShell, .NET runtime installation or elevation. The resizable dialog permits new folders; Unicode and long filesystem paths use `SHGetPathFromIDListEx`. A locked COM apartment owns the modal dialog, and request cancellation closes it. An opt-in native smoke test with PATH empty selected a temporary folder containing spaces and Unicode, returned empty on Cancel, and closed on context timeout. Existing local WebUI tests cover populating a draft, preserving typed paths on cancellation/error, and binding only on explicit Save. Teacher confirmation from the installed Hub and real UserSync-provider delivery remain pending.
