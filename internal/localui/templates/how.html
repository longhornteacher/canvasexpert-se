How it works

Dev is where the product is developed and its download ZIP is built. Unzip the download into the local folder where you want to keep it: that folder is already UserInstall. Run directly there; setup connects apps and Canvas without copying the program into another folder. Optional UserSync holds reusable teacher setup; its provider carries those files between computers. These names describe each folder's role; you do not need to rename your folders.

The Engine

The machinery that lets an agent work with Canvas. It includes starter playbooks, carries no private teacher data, and is replaced when you install a new version.

How do I…?

Update the program
  1. Unzip the new version somewhere else.
  2. Copy its engine folder over the one in your UserInstall. Copy nothing else; your teacher files stay yours.
  3. Double-click webui.cmd. Missing starter files appear on the next hub or MCP launch. Existing copies, including AGENTS.md and playbooks, are not updated automatically.
  4. To adopt a newer instruction or playbook, open Settings, Files and choose Get the new version. Your previous copy is kept in playbook-old.
Get updated instructions or a playbook
  1. Open Settings, Files and choose Get the new version. Your old copy is kept in playbook-old.
  2. Or delete the file from your UserInstall and reopen the hub. That removes the old copy without an archive.
  3. Context files such as feedback voice, courses and students cannot be replaced this way.
Change how the agent behaves
  1. Feedback voice and grading habits: Settings, Preferences.
  2. Student accommodations and notes: Students.
  3. Active courses: Courses.
  4. For other changes, ask the agent to update the appropriate playbook or edit it yourself.
Use another computer
  1. Unzip CanvasExpert-SE on that computer's own drive, not in OneDrive; some districts block syncing programs.
  2. In Settings, select the same UserSync folder. The provider carries reusable teacher setup; CE-SE does not copy it between computers.
  3. Point the agent at this computer's UserInstall and ask it to set up. Connect Canvas on this computer too; credentials, app connections and grading/planning sessions stay local.
Keep student information private
  1. Private student mappings, roster and contacts use .cse in UserInstall or the selected UserSync. Pulled work and drafts stay in UserInstall's courses/.
  2. The agent is instructed not to open .cse.
  3. Private information does not go in the engine folder.
  4. Never put your Canvas token in a file or chat.
Ask the agent for work
  1. Say scoring session: it pulls the work, then asks what to do.
  2. Say draft: it saves scores and feedback but does not post.
  3. For scores, new assignments, New Quizzes and assignment edits, the Engine opens a review page. Review the proposed work and approve it there before posting; say if you want to skip review.
  4. After Canvas accepts a post, the agent reports completion in one line and stops without re-checking Canvas.
  5. Say score and post to set what gets posted; the review page remains the approval step.
