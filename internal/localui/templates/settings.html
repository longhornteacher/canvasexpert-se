How UserInstall and UserSync work

Reusable teacher setup uses UserInstall by default or the saved UserSync folder. UserSync is a local folder; its provider carries changes between computers, and CE-SE does not verify delivery. Grading and planning session files stay in UserInstall.

An empty UserSync folder is initialized from current teacher setup. Existing UserSync data becomes authoritative; newly supported setup files are added only if missing. Local originals are preserved. Use UserInstall copies shared setup back and archives differing local versions.
