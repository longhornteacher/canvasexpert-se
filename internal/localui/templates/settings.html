How Install and Sync work

Teacher instructions, playbooks, guides and preferences use Install by default or the saved Sync folder. Sync is a local folder; its provider carries changes between computers, and CE-SE does not verify delivery. Courses, students and work stay in Install.

An empty Sync folder is initialized from current shareable rules. Existing Sync rules become authoritative; local originals are preserved. Use Install copies shared rules back and archives differing local versions.
