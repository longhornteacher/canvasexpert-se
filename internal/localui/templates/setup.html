Connect Canvas

CanvasExpert needs an access token from Canvas: a long code that lets it work in your courses. You make one in Canvas in about a minute.

  1. In Canvas, choose Account (your picture, far left), then Settings.
  2. Scroll down to Approved Integrations and choose + New Access Token.
  3. For Purpose, type CanvasExpert. For Expires, pick the last day of school. Choose Generate Token.
  4. Copy the long code Canvas shows and paste it below. Canvas shows it only once.

Treat the token like a password: don't email it or paste it into Claude or ChatGPT. CanvasExpert keeps it locked on this PC.
